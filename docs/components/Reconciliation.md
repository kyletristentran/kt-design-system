# Reconciliation

The reconciliation callout discloses figures that disagree across workbook tabs; the risks table states each objection at full strength beside its response.

## Consumer provides
- `.kt-recon` with an eyebrow and a list; each item names the issue in bold, both values, and which one the memo used.
- `table.kt-risks` with two columns, Risk and Response, two or three rows.

## Rules
- Never pick between conflicting figures silently. Use the more conservative one and say so.
- Caution appears as border, bullet and label only, never as a fill behind the text.
- A risk is written as the strongest version of the objection, not a strawman.
