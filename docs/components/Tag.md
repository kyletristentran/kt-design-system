# Tag

Tags label taxonomy (market, asset class, period, tool) and carry no status.

## Consumer provides
- `<span class="kt-tag">` with a short lowercase term for filters and metadata.
- `kt-tag--solid` for the uppercase tool tags on kyletran.dev project cards (ARGUS, Excel, Python).

## Rules
- Never color a tag with semantic or accent colors; that would read as status.
- Keep to one line; wrap the group, not the tag.
