# SectionHeading

Two heading patterns: the tool heading (8px `accent-line` square, uppercase `label`, hairline rule) and the editorial title set in Crimson Text.

## Consumer provides
- Tool: `.kt-section` containing `.kt-section__sq` and a `.kt-label`.
- Editorial: an `h2.kt-title` (or `kt-title--sm`) and an optional `p.kt-subtitle`.

## Rules
- Titles are plain descriptive labels (Selected Work, Experience), never slogans or imperatives.
- Editorial titles belong to kyletran.dev and case studies; tools and reports use the tool heading.
