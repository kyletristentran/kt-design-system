# OutlineButton

The outline button is the kyletran.dev contact control: transparent with a 2px `accent` border, placed only on `band`.

## Consumer provides
- An `<a class="kt-btn kt-btn--outline">` inside a container painted `band`.
- A one-word destination label (Email, LinkedIn, GitHub, Resume).

## Rules
- Only on `band`; `accent` borders on white fall below 3:1.
- Hover fills with `accent` and switches type to `on-accent`.
- Stack full width below 480px, max 280px wide.
