# Mark

The mark is a square `ink` field with initials and an `accent` underscore at 10% of its height.

## Consumer provides
- `<span class="kt-mark">KT</span>`, optionally inside `.kt-lockup` with a `.kt-wordmark`.
- `kt-mark--lg` for covers; `kt-mark--on-band` on `band` fields.

## Rules
- Square, never rounded. Clear space on every side equals the mark's height.
- Never place the mark on an `accent` field.
- The mark is set in type; there is no drawn logo file.
