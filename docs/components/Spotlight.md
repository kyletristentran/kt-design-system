# Spotlight

The spotlight is the single featured case on kyletran.dev: a `band` field with a 3px `accent` top rule, image left and text right.

## Consumer provides
- An `<a class="kt-spotlight">` with `.kt-spotlight__media` (an `<img>` or `<svg>`) and `.kt-spotlight__body`.
- An eyebrow with `.kt-spotlight__rule`, a `.kt-spotlight__title` and a one-line `.kt-spotlight__desc`.

## Rules
- One spotlight per page.
- Accent is legible here because `band` is dark (10.9:1); eyebrow text may use `accent`.
- Stacks to one column below 640px.
